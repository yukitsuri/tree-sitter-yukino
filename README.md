# tree-sitter-yukino

[Tree-sitter](https://tree-sitter.github.io/) grammar and parser for the [Yukino](https://github.com/yukitsuri/yukino) programming language.

## Usage

### Generate & Test

Requires `tree-sitter-cli` and `node`:

```bash
npm install
npx tree-sitter generate
npx tree-sitter test
```

### Parsing files

```bash
npx tree-sitter parse <file.ykn>
```
